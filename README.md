# tambo-web

Frontend Angular de Tambo Market (gateway nginx en el puerto 80).

Parte del proyecto **Tambo Market** (Desarrollo de Aplicaciones Web II - Cibertec).

Repositorio principal con docker-compose y la documentacion completa: https://github.com/LeitoDLight/tambo-market

Para levantar todo el sistema, clona el repositorio principal y ejecuta: `docker compose up -d --build`
